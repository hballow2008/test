# Notes App 

## Setup

### Backend
```bash
cd backend
npm install
npm start
```

Backend runs on http://localhost:5000

### Frontend
Simply open `frontend/index.html` in your browser.

Or use Live Server in VS Code.

## 🎯 Features

### User Mode
- Create notes
- Edit notes
- Delete notes
- Search notes

### Guest Mode
- View notes only (read-only)
- Search notes
